# MCDA – BWM & ELECTRE III

Python implementation of a two-stage Multi-Criteria Decision Analysis (MCDA) model for prioritising supply chain planning improvements at Univar Solutions.

## Methods

- **Non-linear BWM:** Calculates criteria weights using optimisation.
- **ELECTRE III:** Computes concordance, discordance and credibility indices to compare alternatives.
- **Lambda-cut:** Determines the final ranking.
- **Sensitivity Analysis:** Tests changes in lambda values and criteria weights.

## Technologies

- Python
- NumPy
- Pandas
- SciPy
